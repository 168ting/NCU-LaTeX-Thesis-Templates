# NCU-LaTeX-Thesis-Templates
LaTeX thesis templates for National Central University
國立中央大學 LaTeX 碩博士論文樣板

搭配線上編輯器 Overleaf 使用，提供 樣板教學說明書 tutorial for LaTeX，教學內容涵蓋 LaTeX 基礎語法，亦歡迎一般 LaTeX 學習者參考使用。

目前已有多位同學使用本樣板完成論文，並通過國立中央大學博碩士論文系統審核。

## Templates

- Graduate College of Sustainability and Green Energy
- Department of Communication Engineering

## Usage

1. Download the desired template.
2. Upload the files to Overleaf.
3. Compile with the appropriate LaTeX compiler.

## Note

This repository is provided for reference only.
Please refer to the latest thesis formatting requirements of National Central University.
