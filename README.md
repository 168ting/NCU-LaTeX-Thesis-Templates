# NCU-LaTeX-Thesis-Templates
LaTeX thesis templates for National Central University
國立中央大學 LaTeX 碩士論文樣板整理。

## Templates

- Sustainable Energy
- Communication

## Usage

1. Download the desired template.
2. Upload the files to Overleaf.
3. Set the main `.tex` file as the main document.
4. Compile with the appropriate LaTeX compiler.

## Note

This repository is provided for reference only.
Please refer to the latest thesis formatting requirements of National Central University.
